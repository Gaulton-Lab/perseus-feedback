# Perseus Feedback

Feedback and support for [Perseus](https://perseuskb.org)
This repo does not contain Perseus source code. It's for bug reports,
feature requests, and data questions only.

### Get help
- 🐛 [Report a bug](../../issues/new?template=bug_report.yml)
- ✨ [Request a feature](../../issues/new?template=feature_request.yml)
- 📊 [Ask about data](../../issues/new?template=data_question.yml)
- 💬 [General discussion](../../discussions)

Please don't include unpublished data or donor-identifiable information in issues.
