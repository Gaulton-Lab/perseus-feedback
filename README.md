# Perseus Feedback & Support

This repository is the public feedback channel for **Perseus** (perseuskb.org),
the web application for exploring the PanKbase human pancreatic islet
single-nucleus ATAC-seq atlas.

This repo does **not** contain the Perseus source code (that lives in a
private repository). It exists so users can:

- 🐛 Report bugs
- 💡 Request features
- ❓ Ask questions about the data or how to interpret results
- 💬 Discuss the resource with other users (see the **Discussions** tab)

## Before you open an issue

Please check:
1. [Existing issues](../../issues?q=is%3Aissue) — someone may have already asked
2. Our [FAQ discussion](../../discussions) for common data questions

## Opening an issue

Click **New Issue** and pick the template that fits:

| Template | Use for |
|---|---|
| 🐛 Bug Report | Something on the site is broken or behaving unexpectedly |
| ✨ Feature Request | An idea for something Perseus doesn't do yet |
| 📊 Data Question | Questions about specific loci, cell types, ABC links, or scores shown in the app |

## Please don't include

- Unpublished data, donor-identifiable information, or manuscript figures
  not yet public
- API keys or credentials
