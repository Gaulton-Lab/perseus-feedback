# PanKbase App Feedback

Feedback and support for PanKbase-family applications:
- [Perseus](https://perseuskb.org)
- [CFRD Genomics](https://cfrdgenomics.org)
- Liver Genomics
(more coming)

This repo holds no source code — it's for bug reports, feature requests,
and data questions across all apps above.

### Get help
- 🐛 [Report a bug](../../issues/new?template=bug_report.yml)
- ✨ [Request a feature](../../issues/new?template=feature_request.yml)
- 📊 [Ask about data](../../issues/new?template=data_question.yml)
- 💬 [Discussions](../../discussions) — pick the category for your app

Please don't include unpublished data or donor-identifiable info.
